# Descrição Geral

O Sistema Inteligente de Monitoramento e Alerta de Epidemias é uma plataforma digital projetada para auxiliar na triagem inicial de pacientes, reduzir a sobrecarga dos hospitais e permitir o monitoramento em tempo real de possíveis surtos de doenças em Angola.

O sistema utilizará técnicas de Inteligência Artificial para analisar sintomas informados pelos usuários e identificar possíveis condições de saúde, classificando-as por nível de gravidade e contribuindo para a detecção precoce de epidemias.

# Objetivo Geral

Desenvolver uma plataforma inteligente capaz de:
* Auxiliar na triagem de pacientes
* Identificar padrões de doenças
* Detectar e alertar possíveis surtos epidêmicos em tempo real

# Objetivos Específicos

* Reduzir a superlotação hospitalar
* Fornecer orientação inicial ao paciente
* Monitorar a distribuição geográfica de doenças
* Apoiar profissionais de saúde na tomada de decisão


# Consulta Inteligente (IA)

O usuário pode realizar uma consulta inicial através de um sistema de inteligência artificial, informando:
* Sintomas
* Duração dos sintomas
* Intensidade

A IA realiza:
* Análise dos sintomas
